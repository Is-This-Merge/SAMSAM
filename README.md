# SAMSAM

SASA 학생들의 암기 과목 학습을 돕는 Flask 웹 애플리케이션이다. 웹 서버는 Render, 영구 데이터는 CockroachDB Cloud Basic을 사용한다.

개발 단계는 [IMPLEMENTATION_PLAN.md](./IMPLEMENTATION_PLAN.md), 코드 계층과 디렉터리 책임은 [docs/ARCHITECTURE.md](./docs/ARCHITECTURE.md)를 참고한다.

## 로컬 실행

Python 3.11 이상을 준비한 뒤 다음 명령을 실행한다.

```bash
python -m venv .venv
python -m pip install -r requirements.txt
```

`.env.example`을 참고하여 운영체제에 `DATABASE_URL`과 `SECRET_KEY` 환경변수를 설정한다. 그다음 개발 서버를 실행한다.

```bash
flask --app app run --debug
```

- 홈: <http://127.0.0.1:5000/>
- 상태 확인: <http://127.0.0.1:5000/health>

`DATABASE_URL`이 없으면 화면은 로컬 SQLite로 확인할 수 있지만 `/health`는 HTTP 503과 `database: not_configured`를 반환한다.

## 현재 구조

- `app`: Flask 애플리케이션 팩토리와 공통 확장
- `app/models`: 데이터베이스 엔티티와 관계
- `app/services`: 검증, 접근 권한, 문항 구성 등 도메인 로직
- `app/views`: 화면 및 API의 HTTP 요청·응답 처리
- `app/templates`: HTML 템플릿
- `app/static`: CSS, JavaScript, 이미지
- `render.yaml`: Render 배포 설정

## 로그인 없는 로컬 오답 노트

`/mistakes.html`에서 오답 횟수 내림차순으로 문제를 확인한다. 동률은 최근 오답 순이다.
세트·학습 방식 필터, 문제·정답 검색, 20개씩 페이지 보기와 답안 펼치기를 제공한다.
문항별 채점 시 틀린 답만 `localStorage`의 `samsam.mistakes.v1`에 저장하며,
카드의 ‘다시 볼래요’도 포함한다. 반복 회차와 재시작 간 횟수를 누적하고 정답을 맞혀도 삭제하지 않는다.
보기 순서는 식별에 영향을 주지 않으며, 랜덤 빈칸은 원문과 단어 위치를 기준으로 구분한다.
학습 방식은 별도 집계한다. 기록은 브라우저·접속 주소별로 분리되며 서버나 계정에 동기화되지 않는다.
예전 최종 점수에서는 과거 오답 횟수를 복원하지 않는다. 저장 공간 오류는 학습을 막지 않고 안내한다.
오답 노트의 초기화 버튼은 이 기능의 로컬 기록만 삭제한다.

## 테스트 실행

```bash
python -m pytest
node --test tests/*.mjs
```

퀴즈 생성 API는 `POST /api/quizzes`, 단건 조회 API는 `GET /api/quizzes/{id}`이다.

개발·테스트 의존성은 `requirements-dev.txt`로 설치한다. Node.js는 프론트엔드 테스트에만 필요하며 앱 배포에는 필요하지 않다.

현재 객관식, 단어 카드, 빈칸 채우기를 한 학습 세트에 함께 구성할 수 있다. 로그인 사용자는 내 학습실에서 최근 풀이 기록, 공유받은 퀴즈, 공동 편집 기능을 사용하고 퀴즈 완료 후 매치 게임을 실행할 수 있다.

## Render 배포

1. 저장소를 GitHub에 push한다.
2. Render에서 Blueprint로 `render.yaml`을 읽어 서비스를 생성한다.
3. Render의 `DATABASE_URL`에 CockroachDB 연결 문자열을 등록한다.
4. 배포 후 `/health`에서 애플리케이션과 DB 연결을 확인한다.

## Google 로그인 설정

Google Cloud Console에서 OAuth 클라이언트 유형을 **웹 애플리케이션**으로 만들고 다음 callback 주소를 승인된 리디렉션 URI에 등록한다.

- 로컬: `http://127.0.0.1:5000/auth/callback`
- Render: `https://<서비스 주소>/auth/callback`

로컬 `.env` 또는 Render Secret에 `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`을 등록한다. OAuth 자격 증명이나 안전한 `SECRET_KEY`가 없으면 앱은 실행되지만 로그인 버튼은 비활성화된다. OAuth 비밀값은 저장소에 커밋하지 않는다.

`GOOGLE_REDIRECT_URI`에는 Google Cloud Console에 등록한 주소와 글자 단위로 같은 callback 주소를 넣는다. 로컬 권장값은 `http://127.0.0.1:5000/auth/callback`이다. 브라우저 접속 주소와 관계없이 이 값을 사용하므로 `localhost`와 `127.0.0.1` 혼동을 피할 수 있다.

OAuth의 `state`와 로그인 세션 보호를 위해 `.env`의 `SECRET_KEY`도 임의의 긴 값으로 변경해야 한다. 기본값인 `local-development-only` 또는 예시 문자열이 사용되면 Google 로그인은 안전을 위해 비활성화된다.

CockroachDB 연결 문자열과 비밀번호는 저장소에 커밋하지 않는다.

## ERW 샘플 데이터

제공된 PDF 6개를 바탕으로 단어장 5세트, 255개 어휘를 구성했다.
기존 11문항 샘플 5세트는 더 이상 생성하지 않는다.
각 단어장 세트에서 뜻 입력, 본문 빈칸, 문장 배열, 내용 확인을 선택한다.
`app/data/erw_vocabulary.json`에는 단어장 PDF 2~7쪽의 어휘표 255개를 전부 수록했다.
8~19쪽의 반복 연습용 항목은 중복 제외했으며, 주제별로 50·69·49·37·50개씩 나누었다.
명백한 오기는 수정하고 해당 항목에 원문 표기·뜻과 수정 설명을 남겼다.
각 세트 설명에 출처 파일과 페이지를 기록했으며 예문과 독해 문항은 재구성했다.

```bash
flask --app app seed-samples --dry-run
flask --app app seed-samples
```

입력 명령은 현재 `DATABASE_URL`의 DB를 사용하며, 미설정 시 로컬 SQLite를 사용한다.
새 DB는 먼저 `flask --app app db upgrade`로 스키마를 준비한다.
고정 ID로 기존 샘플을 건너뛰므로 반복 실행해도 중복되지 않으며 기존 퀴즈와 풀이 기록은 유지한다.
샘플은 소유자 없는 공개 세트로 추가되며 홈에서 `ERW` 과목으로 검색하고 학습할 수 있다.
기존 샘플의 수정 내용도 보존하므로 JSON을 수정한 뒤 재실행해도 이미 등록된 세트는 갱신하지 않는다.
PDF 원본이나 PDF 추출 패키지는 앱 실행에 필요하지 않다.

### 클라우드 DB 없이 로컬에서 테스트

`local_app`은 `.env`의 `DATABASE_URL`과 관계없이 `instance/samsam-local.db`에 저장한다.
Google 로그인은 비활성화되며 공개 샘플 조회·풀이·채점·매치 게임을 비로그인으로 테스트할 수 있다.

```powershell
.venv/Scripts/python -m flask --app local_app db upgrade
.venv/Scripts/python -m flask --app local_app seed-samples
.venv/Scripts/python -m flask --app local_app run --port 5001
```

브라우저에서 <http://127.0.0.1:5001>을 연다. 샘플과 풀이 기록은 서버를 재시작해도 유지된다.

이전 20개 단어 샘플을 사용 중이면 다음 명령으로 누락된 어휘를 추가한다.
기존 문항 ID·순서·답안·해설과 풀이 기록은 유지하며, 단어장 세트의 제목·설명만 갱신한다.
다른 세트는 수정하지 않고 재실행 시 추가 어휘가 중복되지 않는다.

```powershell
.venv/Scripts/python -m flask --app local_app seed-samples --expand-vocabulary
```

기존 11문항 샘플만 제거하려면 위 명령에 `--retire-legacy`를 추가한다.
이 옵션은 알려진 샘플 ID 5개와 연결된 풀이 기록을 삭제하며, 사용자 소유 세트는 삭제하지 않는다.
번호는 PDF 순서인 01 말벌, 02 디지털 디톡스, 03 우정, 04 새로운 출발, 05 남극 탐험이다.
단어 자체에는 번호를 표시하지 않으며 뜻 입력의 첫 회차는 PDF 순서대로 진행한다.

### 추가 학습 방식

퀴즈 상세 화면에서 다음 학습 방식을 선택할 수 있다.

- **뜻 직접 입력하기**: 단어 카드가 있는 세트에서 영어 단어를 보고 뜻을 입력한다.
  등록된 뜻 전체 또는 쉼표·세미콜론·슬래시로 구분된 뜻 하나를 정답으로 인정한다.
  유니코드 표기와 대소문자·띄어쓰기 차이는 정규화하며, 괄호 설명을 생략한 뜻도 인정한다.
  임의의 유의어나 오타까지 추론하지는 않는다.
- **랜덤 빈칸 고르기**: 설정 화면에서 영어 본문을 입력·수정한다. 기본값으로
  `app/data/article_passages.json`의 PDF 기사 전체 본문을 제공하며 후보 단어 목록이나 사전 문항은 사용하지 않는다.
  `app/services/cloze.py`가 실제 본문의 단어 위치를 추첨하고 원래 위치의 단어를 정답으로 저장한다.
  전체 본문 또는 40/80/120단어 단위로 범위를 지정하고 범위당 1~10개 빈칸을 만든다.
  문단 경계는 범위를 제한하지 않는다. 본문 안의 다른 단어로 보기 4개를 자동 구성한다.
  여러 빈칸을 함께 표시하되 각 빈칸을 차례로 채점하고, 맞힌 빈칸은 본문에 채워 유지한다.
  입력은 최대 30,000자이며 서로 다른 영어 단어가 4개 이상 필요하다.
  재시작마다 새로 추첨하므로 같은 빈칸이 다시 나올 수도 있다.
- **문장 배열**: 코드가 등록된 본문을 문장으로 나누고 매번 최대 5문장을 무작위 추출한다.
  해당 문단의 한국어 해석과 정답 문장 자리만 가린 원문 문맥을 힌트로 제공한다.
  단어를 선택하며, 선택한 단어를 다시 누르면 취소한다. 같은 단어도 개별 토큰으로 구분한다.
- **문단 해석 매칭**: 영어 문단에 맞는 한국어 해석을 고른다. 같은 기사의 다른 문단 해석을
  오답 보기로 사용한다. 기사 전체의 모든 문단과 해석은 `app/data/article_passages.json`에 저장한다.
  과거의 사전 제작 문항 파일은 제거했으며, 출제는 전체 본문 데이터에 기반한다.

기사 본문은 첨부 PDF의 번호가 붙은 본문 문단 전체를 원문 순서로 수록한다.
말벌 16문단(3~4쪽), 디지털 디톡스 13문단(3~4쪽), 우정 7문단(3쪽),
새로운 시작 13문단(4~5쪽), 인듀어런스 10문단(3쪽), 총 59문단이다.
단·페이지를 넘어 이어지는 문단을 연결하고 줄바꿈만 정리했다.
학습 지시문, 어휘 연습, 문제, 용어집은 본문에서 제외한다.
한국어 해석은 영어 원문을 바탕으로 작성한 학습용 번역이다.

네 방식 모두 문항별 즉시 채점과 최종 결과·풀이 기록 저장을 지원한다.
기본 학습을 포함해 정답 문항은 제외하고, 회차가 끝나면 틀린 문항만 다시 푼다.
기본 카드의 ‘알고 있었어요’와 ‘다시 볼래요’는 즉시 채점 후 다음 카드로 이동한다.
정오답은 초록색·빨간색과 문자로 함께 표시한다. 세트 상세 메뉴는 화면 높이에 맞춰 배치한다.
오답이 없어질 때까지 반복하며 재출제 시 입력·선택·배열을 초기화한다.
본문 빈칸과 보기는 같은 학습 중에는 유지하여 실제로 틀렸던 문항을 복습한다.
모든 문항을 맞힌 뒤 최종 답안으로 한 번의 학습 완료 기록을 저장한다.
화면에서 회차·완료 수·남은 문항 수를 확인할 수 있고, 완료 화면의 ‘전체 다시 풀기’로 새로 시작한다.
정답은 서버에서 판정하며 학습 시작 응답에는 정답과 해설을 포함하지 않는다.
학습 토큰은 24시간 유효하고, 도중에 내용이 바뀌면 다시 시작해야 한다.
기존 샘플을 재등록하거나 DB 스키마를 변경할 필요는 없다.

학습 중 숫자 `1`~`6`으로 보기를 선택하고 `Enter`로 정답 확인 또는 다음 문항 진행이 가능하다.
정답 확인 후에는 다음 버튼으로 초점이 이동한다. 한글 조합 중, 채점 요청 중, 키를 길게 누른 상태에서는
단축키가 중복 실행되지 않으며 입력칸에서 숫자를 쓰면 답안 입력으로 처리한다.
단축키 테스트는 `node --test tests/test_study_keyboard.mjs`로 실행한다.


### 셔플·본문 읽기·로컬 기록

오답 노트의 **현재 목록 N문제 테스트**는 세트·방식·검색 필터에 맞는 모든 페이지의 문제를
오답 순서대로 출제합니다. 각 항목의 **이 문제 테스트**로 한 문제만 복습할 수도 있습니다.
맞힌 문제는 해당 테스트에서 제외하고 오답만 반복하며, 재오답은 원래 기록의 횟수에 누적합니다.
기본 카드는 뜻 입력으로 테스트합니다. 신규 오답은 원래 보기를 함께 저장합니다.
보기가 저장되지 않은 과거 기록은 직접 입력으로, 과거 문단 해석 문제는 해석 카드로 복습합니다.
오답 테스트는 로컬 기록으로 채점하며 서버에 풀이 기록을 새로 생성하지 않습니다.

학습 방식 선택 화면의 **셔플 모드**는 문항 순서를 섞으며, 오답 재학습 때도 남은 문항을 다시 섞습니다.
선택은 브라우저에 기억합니다. 매치 게임은 기존의 무작위 배치를 사용합니다.
같은 화면 아래 **본문 · 해석 읽기**에서 PDF 기사 전체 59문단을 원문+해석, 원문만, 해석만으로 볼 수 있습니다.
전체 테마는 사암색이며 정답·오답의 초록·빨강 표시는 유지합니다.

오답은 `localStorage`의 `samsam.mistakes.v1`에 저장하므로 서버/브라우저 종료 후에도 유지됩니다.
항상 같은 브라우저에서 `http://127.0.0.1:5001`로 접속하세요. `localhost` 또는 다른 포트는 별도 저장소입니다.
브라우저 데이터 삭제나 시크릿 창 종료 시에는 기록이 사라질 수 있습니다.

기존 로컬 샘플의 단어장 정정은 다음 명령으로 적용할 수 있습니다. 문항 ID와 기존 풀이 기록은 보존합니다.

```powershell
.venv\Scripts\python -m flask --app local_app seed-samples --correct-vocabulary
```
